# ⚖️ Multi-Category Unit Converter (Tkinter GUI)

A comprehensive desktop **Unit Converter** application built in **Python** using **Tkinter** (`unit_converter_2.py`). Supports **31 different unit conversions** across temperature, currency, mass/weight, length/distance, speed, time, and area through dedicated interactive dialog windows.

---

## 📂 Repository Structure

- `unit_converter_2.py`: Main Tkinter GUI application containing 31 conversion utilities.
- `README.md`: Project documentation.

---

## ✨ Supported Conversions (31 Modes)

| Category | Supported Conversions |
| :--- | :--- |
| **🌡️ Temperature** | `°C → °F`, `°F → °C`, `°C → K` |
| **💱 Currency** | `₹ (INR) ↔ $ (USD)`, `₹ (INR) ↔ £ (GBP)` |
| **⚖️ Mass / Weight** | `Grams ↔ Kilograms`, `Pounds → Kilograms` |
| **📏 Length** | `Centimetres ↔ Metres`, `Metres ↔ Feet`, `Metres ↔ Yards` |
| **🏎️ Speed** | `km/h ↔ mph`, `km/h ↔ m/s` |
| **⏱️ Time** | `Seconds ↔ Minutes`, `Seconds ↔ Hours`, `Days ↔ Hours`, `Seconds ↔ Days`, `Weeks ↔ Days` |
| **📐 Area** | `cm² → m²` |

## 🚀 Getting Started

```bash
git clone https://github.com/sparsh0106/unit-converted-with-tkinter.git
cd unit-converted-with-tkinter
python unit_converter_2.py
```
*(Uses only Python's built-in `tkinter` library—no external dependencies required.)*
